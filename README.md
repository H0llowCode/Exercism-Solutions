# My Exercism Java Solutions

This repository contains my Java code solutions for various exercises on [Exercism](https://exercism.org). 

The goal of this project is to practice object-oriented programming, master Java syntax, and implement clean code practices.

---

## 🛠️ How to Run Tests

To run the test suite for a specific exercise, navigate into that exercise's directory using your terminal and run:

```bash
./gradlew test
```

*Note: If you are using the in-browser editor on the Exercism website, you can simply click the "Run Tests" button instead.*
